# QA Checklist: RPG Academy (v1.0 Production)

## 1. Авторизация и Аккаунт
- [ ] **Регистрация:** Успешное создание пользователя, письмо отправлено на почту.
- [ ] **Верификация Email:** Переход по ссылке из письма активирует `is_active=True`.
- [ ] **Логин:** Успешная генерация JWT токенов, редирект в `/profile`.
- [ ] **Логаут:** Токены удаляются, редирект на главную/логин.

## 2. Выбор Класса
- [ ] **Блокировка (Locked):** Пользователь без пройденного intro-трека не может выбрать класс.
- [ ] **Разблокировка (Unlocked):** Завершение intro-трека открывает доступ к выбору класса.

## 3. Прохождение Миссии (Story -> Quiz -> Code)
- [ ] **Story:** Корректное отображение markdown/текста истории.
- [ ] **Quiz (Неверный ответ):** Ошибка подсвечивается, прогресс не идёт.
- [ ] **Quiz (Верный ответ):** Переход на следующий этап.
- [ ] **Code:** Редактор кода загружается корректно.
- [ ] **Run Code:** Код отправляется в runner, возвращается exit 0 (или ошибка).

## 4. WebSocket и Runner
- [ ] **Подключение:** WS-соединение с Daphne устанавливается без CORS ошибок.
- [ ] **Стриминг:** stdout и stderr корректно транслируются в xterm.js.
- [ ] **Stop:** Принудительная остановка контейнера работает, соединение закрывается.

## 5. Инвентарь и AI Summon
- [ ] **AI Summon:** Использование предмета генерирует подсказку в терминале.
- [ ] **Rate-Limit:** 11-й запрос в минуту к AI Summon выдаёт 429 "Слишком много запросов...".
- [ ] **Расход предметов:** Счётчик `ai_summons` или свитков уменьшается на 1 в БД и UI.

## 6. Локализация (i18n)
- [ ] **Переключение RU/EN:** Изменение языка мгновенно обновляет навигацию и UI.

## 7. Профиль и Лидерборд
- [ ] **Профиль:** Смена `username` сохраняется и мгновенно отображается на странице.
- [ ] **Лидерборд:** Данные загружаются, переключение периодов (all_time, weekly) обновляет список игроков.
