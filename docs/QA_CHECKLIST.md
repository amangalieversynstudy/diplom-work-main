# QA Checklist: RPG Academy (v1.0)

> Проверяй каждый пункт вручную перед демо/деплоем.  
> ✅ = прошло | ❌ = упало | ⚠️ = частично

---

## 1. Регистрация и активация email

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1.1 | POST `/api/auth/register/` с username/email/password | HTTP 201, в консоли Django — лог письма с ссылкой `/api/auth/verify/<uuid>/` |
| 1.2 | Попытка логина до активации | HTTP 401 "No active account" |
| 1.3 | Открыть ссылку из письма (фронтенд `/verify/<uuid>`) | Страница «Путь открыт!», `user.is_active=True` в БД |
| 1.4 | Повторный переход по той же ссылке | Ошибка «Свиток поврежден» (токен использован) |
| 1.5 | POST `/api/auth/resend-verify/` с email | Новое письмо в логах консоли |

- [ ] 1.1 — регистрация создаёт пользователя
- [ ] 1.2 — неактивный аккаунт не логинится
- [ ] 1.3 — активация по ссылке работает
- [ ] 1.4 — повторная активация отклоняется
- [ ] 1.5 — повторная отправка письма работает

## Критический путь для демо (5 минут)

```
Регистрация → активация email → логин → /class (locked) →
/missions/1 (вводный курс, mission 1-4) → /class (unlocked) →
выбрать класс → /worlds (карта с темой) → /missions/N →
запустить код → AI Summon → проверить XP в /profile
```
