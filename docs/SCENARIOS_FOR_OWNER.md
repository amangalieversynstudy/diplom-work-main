# Сценарии проверки для владельца

**Зачем.** За 45 минут своими глазами убедиться, что платформа работает так, как вы будете её обещать
ученикам и преподавателям. Делать на живом сайте `https://diplom-work-main-frontend.vercel.app` **после**
настроек Vercel и Railway (следующий документ).

**Что нужно.** Компьютер, телефон и три тестовых аккаунта: два ученика и один преподаватель. Логины придумайте
(например `test_pupil1`, `test_pupil2`, `test_teacher`), пароли держите у себя, в чат не отправляйте. Для второго
аккаунта откройте сайт в другом браузере или в режиме инкогнито.

**Как читать.** «Делаю» — что нажать. «Должно получиться» — что вы увидите. Если увидели другое, запишите шаг,
сделайте снимок экрана и пришлите: этого достаточно, чтобы найти причину.

## Сценарий 0. Сайт обновился (2 минуты)

1. Откройте сайт, нажмите Ctrl+U, затем Ctrl+F и найдите `buildId`.
2. Должно получиться: значение **не** `Fbi8zizqFtfvEyO5mQEXs` (это старая сборка). Главная страница открывается.

## Сценарий 1. Новый ученик (12 минут)

| Делаю | Должно получиться |
|---|---|
| «Регистрация»: логин, пароль, **почту оставить пустой**, поставить галочку согласия на исследование | вход сразу, без письма; открывается выбор класса |
| Выбрать класс «Python-спеллблейд» | на карте «Змеиные руины»: тропа-змея, джунгли, знак меча |
| Меню «Класс» → выбрать другой класс | карта меняется (у Арканиста Django «Башни Арканы» на сиреневом пергаменте) |
| Нажать на первую миссию карты | открывается миссия с шагами: сюжет, квиз, задача с кодом |
| Квиз: ответить неверно, затем верно | на неверный — понятное сообщение; на верный — шаг засчитан |
| Задача с кодом: написать неверный код, нажать «Запустить» | понятная ошибка или «неверный результат», не сбой сайта |
| Написать верный код, «Запустить» | шаг засчитан |
| Три раза подряд ошибиться на одном шаге | у **половины** учеников появляется баннер помощи, поэтому проверьте на втором аккаунте |
| Нажать «Зелье ясности» | появляется подсказка; зелий стало на одно меньше |
| Позвать «Мудреца» | «Мудрец сейчас недоступен» (нет ключа ИИ): это нормально, предмет не тратится |
| Пройти все шаги, завершить миссию | начислен XP, показан результат миссии |
| «Зал славы», «Мой путь», «Герой» | ученик есть в рейтинге; видны прогресс, серия дней, достижения |
| В профиле снять и вернуть галочку согласия | галочка меняется, ошибок нет |

## Сценарий 2. Таверна (3 минуты)

Если на Railway стоит `SOCIAL_ENABLED=0` (рекомендация на весь пилот):
- в меню пункта «Таверна» нет;
- адрес `/tavern` показывает: «Таверна на этом сервере выключена».

Если вы её включили: со вторым учеником добавьте друг друга в друзья, обменяйтесь подсказкой, основайте гильдию и
сыграйте дуэль. Дуэль работает только по миссиям, которые прошли оба игрока.

## Сценарий 3. Преподаватель и Студия (15 минут)

| Делаю | Должно получиться |
|---|---|
| Регистрация, выбрать «Я преподаватель», ввести код из `TEACHER_INVITE_CODE` | вход; в меню «Кабинет», «Студия», «Аналитика» |
| То же с неверным кодом | понятное сообщение, аккаунт преподавателя не создаётся |
| «Студия» → «Новый курс» → шаблон «Python с нуля» → «Создать курс» | курс с 4 главами, 8 миссиями, по 3 шага в каждой |
| Открыть шаги миссии → шаг «Теория» → изменить текст: строка `## Заголовок`, пустая строка, строка `- пункт` | ниже блок «Так увидит ученик» показывает оформленный заголовок и список |
| Нажать кнопки над полем текста («Заголовок», «Список», «Блок кода») | разметка вставляется сама |

| Отметить курс «Опубликован» и у миссии нажать «Опубликовать» | у курса и миссии пропадает «Черновик» |
| Скопировать «Код класса» из блока «Класс» | код (8 символов) и ссылка-приглашение |
| «Копировать курс» → подтвердить | появляется «… (копия)»: черновик с новым кодом |

## Сценарий 4. Класс: ученик и кабинет (8 минут)

1. Второй ученик: на карте «У меня есть код класса» → ввести код класса → дать согласие.
2. Курс преподавателя появился у ученика; решить один шаг.
3. Преподаватель → «Кабинет»: ученик в списке; блок «Сейчас на платформе» показывает его действие.
4. Нажать на ученика: видно, какие шаги он решил, сколько было попыток.

Важно: самостоятельно зарегистрированный преподаватель видит только учеников **своих** классов. Чтобы он видел
учеников встроенных курсов (`python-intro`, `python-continued`), его должен сделать «проверенным» суперпользователь
в `/admin/` (инструкция в следующем документе).

## Сценарий 5. «Глазами студента» (3 минуты)

1. Преподаватель включает переключатель «Глазами студента».
2. Проходит шаг: сверху плашка режима, **опыт не начисляется**, в рейтинг он не попадает.

## Сценарий 6. Телефон (5 минут)

Откройте сайт на телефоне, зарегистрируйте или войдите учеником. Проверьте: карта показывается вертикальной тропой,
миссия читается без горизонтальной прокрутки, редактор кода открывается, кнопка «Запустить» нажимается.

## Сценарий 7. Данные для исследования (5 минут, на сервере)

Команды запускаются по инструкции из следующего документа (`railway ssh`):

```
python manage.py pilot_check
python manage.py pilot_report
```

Должно получиться: в `pilot_check` **нет строк `[FAIL]`** (строки `[WARN]` про публичный Judge0, почту и Мудреца
ожидаемы). В `pilot_report` ученики без согласия и аккаунты, созданные **до** `PILOT_STARTED_AT`, не входят в числа.

## Сценарий 8. Что-то пошло не так (3 минуты)

- Неверный пароль → понятное сообщение, не белый экран.
- «Выйти» и снова «Войти» → прогресс на месте.
- Забыли пароль, а почты нет → пароль восстанавливает только суперпользователь через `/admin/`. Предупредите об
  этом учеников.

## Можно запускать, если

Сценарии 0–6 прошли без блокирующих сбоев, `pilot_check` без `[FAIL]`, а репетиция на 2–3 знакомых прошла по тем же
шагам. Если что-то не получилось, пришлите номер сценария и снимок экрана.
