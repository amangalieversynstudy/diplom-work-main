## Открытые вопросы (не исправлены сегодня)

1. **Целостность скрытых проверок кода (средний) — исправлено в тот же день, см. № 11 выше.** Сравнение
   с ожидаемыми значениями перенесено на сервер, поэтому многофайловая отправка в Judge0 не понадобилась.
   Остаётся слабее проверка, где нет ни одного сравнения со значением (только условия «да/нет»):
   `pilot_check` перечисляет такие шаги, у встроенных курсов их нет.
2. **Токены входа хранятся в `localStorage` (средний).** При уязвимости XSS их можно украсть. Сейчас весь HTML
   от преподавателей проходит через DOMPurify с узким списком тегов. План: полная политика `script-src` с
   nonce или refresh-токен в httpOnly cookie.
3. **Смена e-mail без ввода текущего пароля (низкий).** План: спрашивать пароль.
4. **Схема API `/swagger.json` и `/redoc/` открыта всем (низкий).** Репозиторий и так публичный; при желании
   закрыть для всех, кроме staff.
5. **Код учеников уходит на публичный `ce.judge0.com` (приватность).** Упомянуть в согласии или поднять свой
   Judge0 (`pilot_check` об этом предупреждает).
6. **JWT для WebSocket передаётся в адресе (низкий):** может попасть в логи прокси.
7. **Регистрация сообщает, что логин или почта заняты (низкий):** компромисс удобства.
8. **Проверка зависимостей в CI** запускается только для pull request в `main` и не блокирует сборку.
9. **Конфигурация для VPS** (`nginx.conf`, `deploy/`, `backend/Dockerfile` от root) в текущем деплое не
   используется; если вернуться к VPS — сначала обновить.

- `DJANGO_SUPERUSER_PASSWORD` — длинный уникальный пароль; `ANALYTICS_EXPORT_SALT` — задан и не меняется.
